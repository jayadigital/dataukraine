# Osnova Ukrainian Dataroom

## Що створено

Osnova Ukrainian Dataroom об'єднує 10 публічних кутків даних про Україну:
НБУ, Держстат, Open Budget, OECD, World Bank, ILOSTAT, IMF, Eurostat,
UN Comtrade і Trading Economics. Каталог індексує 2 426 наборів та
1 282 243 спостереження, але не завантажує їх усі у браузер.

Кожен куток має власний сайт, каталог, сторінку кожного набору, графік,
пояснення простою мовою, аудит покриття та експорт JSON/CSV/Markdown.
Локальний SQLite Data Lab дає повний SQL-доступ для дослідження схем і сирих
рядків.

## Прогнози

Універсальна сторінка показує три окремі траєкторії зростання ВВП:

- IMF WEO: факт до 2025 року та прогноз 2026-2031.
- World Bank GEP: опублікована траєкторія до 2028 року.
- Trading Economics: поточне значення та чотири квартальні горизонти.

Прогнозні відрізки позначені пунктиром. Їх не усереднюють: різні організації
мають різні дати випуску, припущення та методології.

## Що можна порівнювати

Перший семантичний шар містить п'ять тем: зростання ВВП, інфляція,
безробіття, державний борг і зовнішній баланс. Для кожного джерела збережено
код ряду, одиницю, частоту та роль: офіційний факт, оцінка, YTD або прогноз.

Схожі назви не означають однаковий показник. Перед накладанням графіків
потрібно перевірити одиницю, населення, сезонне коригування, поточні чи
постійні ціни та статус публікації.

## Відомі межі

- 68 Eurostat кубів порожні для України або вимагають асинхронного експорту.
- 35 IMF індикаторів зараз не мають значень для України.
- Comtrade у поточному публічному контракті повернув 1996-2024 роки.
- Trading Economics API потребує ключа для повної історії; публічно доступний
  прогнозний зріз уже включено.
- Місцеві бюджети потребують окремого backfill за кожним `codebudg`.

Ці прогалини показані в аудиті, а не приховані чи заповнені припущеннями.

## Операційна модель

SQLite використовується локально для повного аналізу. Малі файли
JSON/CSV/Markdown публікуються як незмінні релізи у приватному GCS. Один
Cloud Run API читає лише потрібний файл, а Cloudflare кешує його і віддає
інтерфейс на окремих доменах. Архітектура масштабується від майже нульової
вартості без постійного сервера бази даних.
