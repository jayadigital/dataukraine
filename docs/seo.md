# DataUkraine SEO surface

`https://dataukraine.proto.fund` is the canonical public origin for the
DataUkraine data room. The older `ukraine.proto.fund` and corner subdomains
remain compatibility entry points, but public HTML requests resolve to the
canonical origin with a permanent redirect where appropriate.

## Crawl contract

- `/robots.txt` permits the public catalogue and points to the sitemap.
- `/sitemap.xml` is generated by the Worker from the public graph index and
  includes catalogue, corner, dataset and stable graph-ID pages.
- `/api/` is excluded from crawling because the API is a machine-readable
  distribution layer, not a second HTML catalogue.
- `/embed/` is excluded to avoid indexing iframe duplicates; the canonical
  `/id/{graph-id}` page remains indexable.

## Page metadata

HTML pages receive server-side metadata before the browser JavaScript runs:

- canonical URL and Ukrainian/English `hreflang` alternates;
- title, description, Open Graph and Twitter metadata;
- `WebSite`, `WebPage`, `Dataset` and `BreadcrumbList` JSON-LD where a graph
  or dataset is addressable;
- a small no-JavaScript fallback containing the page title, description and
  canonical link.

Dataset JSON-LD identifies the stable graph code and links to the JSON data
distribution. This makes the catalogue understandable to search engines and
AI indexing systems without exposing internal database or ingestion details.
