# DataUkraine API

The public API is read-only and does not require a key. It is served by the
universal Ukraine domain and returns JSON unless an explicit export format is
requested.

Base URL: `https://ukraine.proto.fund/api/v1/ukraine`

## Discovery

| Method | Path | Purpose |
| --- | --- | --- |
| `GET` | `/openapi.json` | OpenAPI 3.1 contract generated by the data API |
| `GET` | `/` | API index and release metadata |
| `GET` | `/corners` | List source corners and coverage |
| `GET` | `/corners/{corner}` | One corner and its release metadata |
| `GET` | `/corners/{corner}/datasets` | Search and paginate datasets |
| `GET` | `/corners/{corner}/datasets/{dataset}` | Dataset metadata and indicators |

Dataset search accepts `q`, `limit`, and `offset`:

```text
/corners/wb/datasets?q=steel&limit=25&offset=0
```

## Series and exports

| Method | Path | Purpose |
| --- | --- | --- |
| `GET` | `/corners/{corner}/datasets/{dataset}/series` | Bounded graph series |
| `GET` | `/corners/{corner}/datasets/{dataset}/rows?part=1` | One bounded raw chunk |
| `GET` | `/corners/{corner}/datasets/{dataset}/export/csv` | CSV export |
| `GET` | `/corners/{corner}/datasets/{dataset}/export/json` | JSON export |

Use `start_year`, `end_year`, and the dataset-specific parameter filters when
available. A client should not assume that every dataset is annual: retain
the returned frequency, period, unit, and status fields.

```bash
curl 'https://ukraine.proto.fund/api/v1/ukraine/corners/imf/datasets/ngdp_rpch/series?start_year=2020&end_year=2031'
```

## Universal and foresight endpoints

| Method | Path | Purpose |
| --- | --- | --- |
| `GET` | `/frames/{year}` | Curated frame for a year |
| `GET` | `/forecasts` | Published forecasts and coverage horizons |
| `GET` | `/reports/latest` | Latest generated change report |

The catalogue index is also available as a static file at
`/api/data/universal.json`. Static files are useful for discovery; use the API
series route when a model needs a bounded, current response.

## Operational endpoints

`GET /api/health` checks the Cloudflare shell. `GET /api/cloud-health` checks
the Cloud Run data service. Public mutation and refresh routes are not exposed
by the browser worker; release publishing remains authenticated and outside
the public API contract.

## Client rules

1. Cache manifests and metadata, but respect the source release timestamp.
2. Use the returned source metadata (`endpoint`, `sourceUrl`, or source
   references, depending on the route) for attribution and citation.
3. Do not turn `partial`, `ytd`, `estimated`, `modelled`, or `forecast` points
   into final observed values.
4. Compare indicators only after checking unit, frequency, population, price
   basis, seasonal adjustment, and status.
5. Treat an empty or deferred dataset as an explicit source result, not as a
   zero.
